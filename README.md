# EncryptEdge Labs — Shared Assets

Brand assets used across all 20 program track repositories.
Reference any file via its raw GitHub URL.

## How to reference an asset in your README

```markdown
![Severity Badge](https://raw.githubusercontent.com/EncryptEdge-Labs/encryptedge-assets/main/badges/severity/critical.svg)
```

## Folder Structure

| Folder | Contents |
|---|---|
| logos/ | EncryptEdge Labs logo variants (dark, light, icon-only) |
| badges/severity/ | Critical, High, Medium, Low, Informational SVG badges |
| badges/tiers/ | Pass, Verified, Portfolio Grade, Hall of Fame SVG badges |
| diagrams/ | Draw.io templates for threat model, DFD, risk matrix |
| icons/ | Tool icons, track icons |

## Usage in intern repositories

Add this to the top of your README.md to display your submission tier badge:

```markdown
![Tier](https://raw.githubusercontent.com/EncryptEdge-Labs/encryptedge-assets/main/badges/tiers/verified.svg)
```
